# 🏷️ 슬기로운 중학생활

> 한 줄 소개: 등교부터 하교까지, 중학생의 하루에 필요한 시간표·학사 일정·급식·숙제·용돈 기입장·미니게임을 한곳에 모은 생활 도우미 앱

- **작품 소개 페이지용 짧은 소개글** (공백 포함 20자 이내):
  > 등교부터 하교까지 생활 앱
- **앱 바로가기**: https://wish0323-web.github.io/Public/
- **개발자**: ○학년 ○반 ○○○

---

## 1. 개발 의도

이 앱을 왜 만들게 되었나요? 어떤 불편함이나 필요를 발견했나요?

- 중학생의 하루에는 확인할 것이 많습니다. 시간표, 학교 행사, 급식 메뉴, 준비물, 숙제, 용돈이 서로 다른 곳에 흩어져 있어서 하나씩 찾아봐야 했습니다.
- 급식 알레르기는 식단표의 번호를 직접 읽고 대조해야 해서 놓치기 쉽습니다.
- 그래서 정보를 **"언제, 어디서 쓰는가"** 를 기준으로 나누어 한 앱에 모았습니다. 하루의 순서(등교 → 학교 → 급식 → 하교)와, 시간과 상관없이 쓰는 것(생활)으로 구분했습니다.
- 글자 크기와 고대비 모드를 넣어, 읽기 편한 정도가 서로 다른 학생도 쓸 수 있게 했습니다.

## 2. 적용 대상

누가, 언제, 어디서 사용하나요?

- 사용 대상: 중학생(학교 이름을 검색해서 전국 어느 학교든 선택할 수 있음), 급식 알레르기가 있는 학생
- 사용 상황: 아침 등교 전, 수업 중, 점심시간, 하교 후, 쉬는 시간

## 3. 주요 기능과 사용 방법

**분류 기준: 언제, 어디서 쓰는가**

| 카테고리 | 분류 기준 | 들어 있는 기능 |
| --- | --- | --- |
| 🎒 등교 | 집에서 나서기 전에 확인하는 것 | 등교까지 남은 시간, 오늘 챙길 과목, 체육복 알림, 가까운 D-day, 등교 준비물 체크리스트 |
| 📚 학교 | 학교에서 수업을 들을 때 확인하는 것 | 시간표, 학사 일정, 내 D-day, 숙제 |
| 🍱 급식 | 점심시간에 먹는 급식에 관한 것 | 오늘·주간·월간 급식, 급식 예보, 알레르기 경고, 급식 일기 |
| 🏡 하교 | 학교를 마친 뒤에 확인하는 것 | 하교까지 남은 시간, 내일 미리보기, 남은 숙제 알림, 하교 후 할 일 체크리스트 |
| ✨ 생활 | 시간과 상관없이 언제든 쓰는 것 | 용돈 기입장, 공부 타이머, 미니게임, 설정 |

| 기능 | 설명 |
| --- | --- |
| 자동 카테고리 | 앱을 열면 지금 시각에 맞는 카테고리가 먼저 열립니다. (예: 점심시간에는 급식) |
| 급식 예보 | 오늘 급식에 내 취향 점수(0~100)를 매겨 ☀️⛅☁️🌧로 보여 줍니다. 메뉴를 눌러 ♥ 좋아요 / ✕ 싫어요를 남기면 점수가 나에게 맞춰지고, 별점을 남기면 다음 예보에 자동으로 반영됩니다. |
| 알레르기 경고 | 내 알레르기 성분을 체크해 두면, 해당 성분이 들어간 메뉴를 빨간색으로 표시하고 주의가 필요한 날을 알려 줍니다. |
| 시간표 · 하교 시간 | 학년과 반을 설정하면 이번 주 시간표를 과목별 색상으로 보여 주고, 마지막 교시를 기준으로 하교 예상 시각과 남은 시간을 알려 줍니다. |
| 학사 일정 · 내 D-day | 학교 행사를 D-day와 함께 보여 주고, 시험이나 수행평가 날짜를 직접 등록할 수 있습니다. |
| 숙제 노트 | 과목, 내용, 마감일을 적어 두면 마감이 된 숙제를 등교 화면과 하교 화면에서 알려 줍니다. |
| 용돈 기입장 | 수입과 지출을 기록하고, 이번 달 분류별 지출 통계와 저축 목표 달성률을 보여 줍니다. |
| 공부 타이머 | 15·25·40분 집중 시간과 5분 쉬는 시간을 반복하며, 오늘과 최근 7일의 공부 시간을 기록합니다. |
| 미니게임 | 카드 짝 맞추기와 구구단 스피드 퀴즈가 있고, 최고 기록이 저장됩니다. |
| 설정 | 글자 크기(보통·크게·아주 크게), 고대비 모드, 기록 백업과 복원을 지원합니다. |

**사용 방법**

1. 앱 주소에 접속합니다.
2. 학교 이름을 검색해서 우리 학교를 선택합니다.
3. 학교 정보가 불러와지지 않으면 ‘샘플 데이터로 둘러보기’를 눌러 체험합니다. (인증키가 있다면 ‘생활 > 설정’에 입력합니다.)
4. 아래쪽 메뉴에서 지금 필요한 카테고리를 고릅니다.
5. 처음 한 번, ‘학교’의 시간표에서 학년·반과 등교 시각, 수업 시간을 설정합니다.
6. ‘급식’의 알레르기 설정에서 내 알레르기 성분을 체크하고, 메뉴를 눌러 취향을 남깁니다.

**사용한 공공데이터와 알려 둘 점**

- **공공데이터**: 교육부 나이스(NEIS) 교육정보 개방 포털의 학교정보, 급식식단정보, 학사일정, 시간표 (https://open.neis.go.kr)
- 급식 예보 점수는 "내가 좋아하는 메뉴가 얼마나 있는가"로 계산한 값이며, 영양이나 맛을 평가하는 점수는 아닙니다.
- 하교 시각은 학교가 공개한 데이터가 없어서, 시간표의 마지막 교시와 내가 설정한 수업 시간으로 계산한 예상값입니다.
- **나이스 인증키는 코드에 포함하지 않았습니다.** 키 없이 호출하면 나이스가 한 번에 5건까지만 주기 때문에, 날짜 범위와 교시를 나누어 여러 번 요청해서 급식·일정·시간표를 모아 보여 줍니다. 키가 있으면 앱의 설정에서 입력할 수 있고, 입력한 키는 사용하는 기기에만 저장됩니다. 학교 선택 화면의 ‘샘플 데이터로 둘러보기’로 전체 기능을 체험할 수도 있습니다.
- 알레르기 정보는 참고용입니다. 정확한 내용은 학교 급식실에서 꼭 확인하세요.
- 취향, 일기, 숙제, 용돈 기록은 사용하는 기기의 브라우저에만 저장되며, 서버로 보내지 않습니다.

## 4. 기대 효과

이 앱을 쓰면 무엇이 좋아지나요?

- 등교 전부터 하교 후까지 필요한 정보를 한 앱에서 확인할 수 있어, 준비물과 숙제를 빠뜨리는 일이 줄어듭니다.
- 알레르기가 있는 학생이 급식을 더 안전하게 먹을 수 있습니다.
- 용돈 기입장과 저축 목표로 소비 습관을 돌아보게 됩니다.
- 글자 크기와 고대비 모드로 더 많은 학생이 불편 없이 쓸 수 있습니다.
- 개인정보를 서버에 모으지 않아 안심하고 쓸 수 있습니다.

## 6. 사용한 AI와 제작 과정

- **사용한 AI 도구**: Claude (Anthropic)
- **처음에 AI에게 한 요청(프롬프트)**:
  > 일단 앱부터 만들자. 3 참고해서 일단 결정부터 하게 네가 아이디어 내 봐.
  >
  > (이후) 조금 더 복잡하고 공공 데이터와 학교 두 가지를 모두 포함한 앱이면 좋을 것 같아.
- **AI가 만든 결과에서 내가 고치거나 추가한 부분**:
  - AI가 낸 여러 아이디어 중에서 급식 알레르기 분석을 직접 골랐고, "등교 브리핑과 합치면 학교생활이 편해질 것 같다"고 방향을 정했습니다.
  - 나이스 인증키를 직접 발급받았고, 키가 코드에 공개되면 안 된다는 점을 알게 되어 키를 코드에서 빼고 사용자가 설정에서 직접 입력하도록 바꾸게 했습니다.
  - "급식만으로는 약하다"고 판단해 시간표, 학사 일정, 등교·하교, 용돈 기입장, 미니게임으로 기능을 넓히도록 요청했습니다.
  - 급식 궁합 기능을 삭제하기로 결정했고, 앱 이름을 "슬기로운 중학생활"로 정했습니다.
  - 기능을 "언제, 어디서 쓰는가"라는 기준으로 나누어 카테고리를 만들도록 요청했습니다.
  - 디자인이 마음에 들지 않아서 더 규칙적이고 예쁘게 다시 고치도록 요청했습니다.
  - 직접 실행해 보고, 학교 검색이 실패하는 문제를 찾아 AI에게 알렸습니다.
- **어려웠던 점과 해결한 방법**:
  - 학교를 검색하면 "검색에 실패했어요"가 나왔습니다. 인증키가 없을 때는 한 번에 가져올 수 있는 자료가 5건으로 제한된다는 것을 알게 되었고, 요청 개수를 고치고 실패 원인이 화면에 나오도록 바꿔서 해결했습니다.
  - 인증키를 어디에 넣어야 하는지 몰랐고, 코드에 넣으면 GitHub에서 누구나 볼 수 있다는 점을 알게 되었습니다. 그래서 키를 코드에서 빼고, 사용하는 기기의 설정에서 입력하면 그 기기에만 저장되는 방식으로 바꿨습니다.
  - GitHub에서 파일을 올리는 방법이 헷갈렸습니다. 저장소 화면의 "uploading an existing file"로 올리고, Settings → Pages에서 주소를 만드는 방법을 배웠습니다.
  - 학교가 하교 시각을 공개하지 않아서, 시간표의 마지막 교시와 설정한 수업 시간으로 계산하는 방식으로 바꿨습니다.
